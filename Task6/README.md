Nationality Detection Model
📌 Project Overview

This project is a Nationality Detection System built using the DeepFace library.
The model analyzes a given image and predicts the dominant race/nationality.


📁 project-folder/
│── gui_app.py              # GUI application to run the model
│── model.pkl               # Trained model (if applicable)
│── requirements.txt        # Required Python packages
│── README.md                # Project documentation
📁 data/
    ├── nationality/
        ├── indian/
        ├── us/
        ├── african/
        ├── other/
