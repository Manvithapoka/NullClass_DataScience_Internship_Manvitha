Internship task submissions for NullClass Data Science Internship.

## 🚀 Tasks Overview

Task 1 – Long Hair Identification

Model to classify whether a person has long hair or not.

Includes GUI using Tkinter.

Task 2 – Senior Citizen Identification

Detects age & gender from video/webcam.

Identifies if a person is a senior citizen (60+).

Task 3 – Age and Emotion Detection from Voice

Processes male voices only.

Rejects female input with a message.

Task 4 – Sign Language Detection

Identifies ASL alphabet signs.

GUI included.

Task 5 – Car Color Detection

Detects car colors from images.

GUI included.

Task 6 – Nationality Detection

Detects nationality from facial features.
